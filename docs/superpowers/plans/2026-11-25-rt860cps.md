# RT-860 CPS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Linux desktop editor for the Radtel RT-860's channels, zones and settings, with safe read/write over the programming cable.

**Architecture:** `rt860core` static library (packet format, image layout, radio session and write procedure) with no GUI dependency, tested against a simulated radio; a Qt Widgets front end on top. Structure, names and safety behaviour follow `../../Quansheng/k5editor`.

**Tech Stack:** C++20, Qt 6 (Core, Widgets, Test), CMake + Ninja, CPack (DEB, TGZ).

**Spec:** `docs/design.md` (protocol and every byte offset are there; copy values from it, not from memory).

## Global Constraints

- Namespace `rt860`; binary `rt860cps`; licence GPL-3.0-or-later.
- Image size 221184 bytes, areas in `.88dat` order: CFG 4096, Channels 49152, FM 4096, Time 32768, Zones 131072.
- Never write `CFG[0..11]` with anything but what the radio holds.
- Unknown bytes and bits are preserved on every encode.
- GUI write action stays disabled until a read from a radio succeeded in this session.

## Review Focus

- Channel whose stored list positions are out of range (e.g. mode 7): shown as damaged, not crashed on, not silently rewritten.
- Name with non-ASCII or over 16 GBK bytes: truncated on a character boundary, never a half character.
- Radio answers with a bad checksum or goes silent mid-read: clear error, port closed, image unchanged.
- File of the wrong size opened: refused with a message.
- Zone listing a channel that is empty or index >= 1024: kept as stored, shown as such, count recomputed only on edit.

Each has a test in the task that owns the code (2, 2, 4, 2, 3).

### Task 1: Scaffold and packet format

**Files:** `CMakeLists.txt`, `src/core/protocol.{h,cpp}`, `tests/test_core.cpp`

**Produces:**
- `quint8 rt860::checksum(const QByteArray &bytes)`
- `QByteArray connectCommand()`, `endCommand()`, `readCommand(quint16 block)`, `writeCommand(quint8 cmd, quint16 index, const QByteArray &data1024)`
- `std::optional<QByteArray> takeReadReply(QByteArray &buffer, quint16 block)` — throws `ProtocolError` on bad header or checksum, nullopt when incomplete.

- [ ] Tests: `readCommand(8) == 52 00 08 5A`; `connectCommand() == 34 52 05 10 9B`; write packet is 1028 bytes with last byte = sum; reply with flipped byte throws.
- [ ] Implement, run `ctest --test-dir build`, expect pass.

### Task 2: Image, channels, tones

**Files:** `src/core/layout.{h,cpp}`

**Produces:** constants `CfgSize, ChannelsSize, FmSize, TimeSize, ZonesSize, ImageSize`, offsets `CfgOffset, ChannelsOffset, FmOffset, TimeOffset, ZonesOffset`; `QByteArray blankImage()`; `struct Channel` with `decodeChannel(image, index)`, `encodeChannel(image, index, channel)`, `channelProblems(image, index)`; `toneText(quint16)`, `parseTone(QString, quint16&)`, `allToneTexts()`; `QByteArray encodeName(const QString&, int maxBytes)`, `QString decodeName(const QByteArray&)`; option-list accessors.

- [ ] Tests: round trip of a full channel; the CPS default VFO record decodes to 400.55500 / 145.55500 MHz; `parseTone("88.5") == 0x1375`, `"D023N" == 0x2013`, `"D023I" == 0x3013`; empty channel encodes to 48 x `FF`; unknown bits in bytes 24-31 survive an encode; out-of-range mode reported by `channelProblems`; 17-byte GBK name truncated to a whole character.
- [ ] Implement, run, pass.

### Task 3: Zones, DTMF, settings

**Files:** `src/core/layout.{h,cpp}` (continued)

**Produces:** `struct Zone { QString name; QList<quint16> channels; }`, `decodeZone`, `encodeZone` (count written to bytes 0 and 1); `dtmfCode(image, i)`, `setDtmfCode(image, i, text)`; `struct Setting`, `settings()`, `findSetting`, `settingValue`, `setSettingValue` (same shape as k5editor's).
